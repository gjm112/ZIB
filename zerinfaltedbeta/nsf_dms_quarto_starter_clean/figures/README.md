# Figures

Store proposal figures generated from real analyses here.

No placeholder or fabricated figures are included in this starter project.
Add figures only when they represent actual preliminary results, simulations,
methodological illustrations, or other content appropriate for the proposal.

Suggested workflow:
  1. Generate the figure in an R script under `R/`.
  2. Save it into this directory.
  3. Include it from the relevant section `.qmd` file.
